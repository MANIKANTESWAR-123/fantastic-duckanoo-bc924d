One-time setup (2 minutes)

This page stores its data as a file in your GitHub repo (the one you already deployed to Netlify). No new service — just a small access key so the page can read and save to it.

  1. On GitHub → tap your profile photo → Settings
  2. Scroll down left menu → Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Name it anything, e.g. "ledger"
  5. Under Repository access, choose Only select repositories → pick your ledger repo
  6. Under Permissions → Repository permissions → Contents, set to Read and write
  7. Generate token → copy it (starts with github_pat_)
  8. Fill in the three fields below

Your friend does this same setup once on their own phone — same repo, branch, and token — so both of you write to the same file. Anyone with this token can edit that one repo, so keep it just between you two.
